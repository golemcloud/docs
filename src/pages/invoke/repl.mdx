## Golem REPL

Once you have a component using `golem` commands,
you can spin up a REPL to interact with your functions.

There are multiple REPLs in Golem - TypeScript and Rust but currently the most feature complete is the TypeScript one.
It is possible to use any REPL with any agents, no matter the language they are implemented in.

For example, using the [quickstart example](/quickstart):

```shell
golem repl
```

```shell
>>> const a1 = await CounterAgent.get("agent-1")
>>> const a2 = await CounterAgent.get("another")
>>> a1.increment()
1
>>> a1.increment()
2
>>> a2.increment()
1
```

The REPL also contains built-in commands corresponding to CLI commands so it is possible to build, deploy and manage agents without leaving the REPL. These commands are available with the `:` prefix. Use the tab-completion to discover them.
